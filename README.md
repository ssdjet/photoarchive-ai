# PhotoArchive AI

AI-powered photo archive: automatic tagging, face recognition, and smart semantic search over your photo collection.

## Features (planned)

- 📥 Import photos from local folders and cloud storage
- 🏷️ Automatic tagging with AI models (objects, scenes, people)
- 😊 Face recognition and clustering
- 🔍 Semantic search across the archive ("sunset on the beach, 2023")
- 🗂️ Timeline and map views
- 📦 Deduplication and storage optimization
