# Руководство пользователя

## Дашборд

Сводка архива: количество фото, лиц, тегов, размер, прогресс индексации, предупреждения
(дубликаты, битые файлы, fallback-режимы AI/Qdrant/Redis). Кнопка «Запустить полную индексацию»
начинает фоновый обход: EXIF, миниатюры, эмбеддинги, лица, дубликаты. Повторный запуск идемпотентен —
неизменённые файлы пропускаются.

## Поиск

- Текст: семантический запрос (CLIP, когда настроен) или поиск по метаданным/тегам (fallback).
- Фильтры: диапазон дат съёмки, локация, кластер лиц, стиль, тег.
- Рядом бейдж показывает движок: `Qdrant vector search`, `Local vector fallback` или `Metadata search`.

## Дубликаты

Группы точных (SHA-256) и визуальных дубликатов. Выберите каноническую версию радиокнопкой,
остальные можно удалить, переместить или пропустить. Операции над >10 файлами требуют подтверждения.

## Лица

Автоматические кластеры лиц. Переименуйте кластер (имя человека), объедините кластеры одного человека
(галочки + «Объединить выбранные»), разделите: откройте кластер, снимите лишние фото и создайте новый кластер.

## Карточка фото

Клик по фото в поиске: полные метаданные (EXIF, камера, дата, GPS, адрес), теги, участники, мини-карта.
Отсюда же доступны операции с файлом: удалить, копировать, переместить — все с подтверждением и записью в лог.

## Карантин

Битые/нечитаемые файлы переносятся в карантин (`QUARANTINE_FOLDER`) с причиной. Список и причины — в разделе
«Карантин» / в предупреждениях дашборда. Файлы не удаляются.

## Логи

Журнал операций: индексация, AI, файловые операции (что/когда/источник/назначение), ошибки.
Фильтр по уровню: debug/info/warn/error.

## Настройки

Корневая папка архива, пути к ONNX-моделям, включение OCR, резервная копия БД (SQLite backup).
Настройки хранятся локально в SQLite.

## Приватность

Все данные остаются на вашем компьютере: БД SQLite, вектора Qdrant локально, эмбеддинги лиц локально.
Приложение не делает сетевых запросов к внешним AI-сервисам.
