# User guide

## Первый запуск

1. Откройте `http://localhost:3000`.
2. Перейдите в «Настройки» и проверьте корень архива.
3. На «Дашборд» нажмите «Запустить полную индексацию».
4. Следите за прогрессом. Битые файлы будут перемещены в карантин и отображены в предупреждениях.

## Поиск

- Вводите запрос на русском или английском.
- Фильтры: дата, локация, человек, стиль.
- При настроенном CLIP text модели поиск использует Qdrant/SQLite vector embeddings; без модели включается metadata search по именам, папкам, тегам и локациям.

## Дубликаты

- Откройте «Дубликаты».
- Выберите canonical version.
- Доступны действия: пометить копии, переместить копии, удалить копии, пропустить группу.
- Удаление требует явного подтверждения.

## Лица

- Откройте «Лица».
- Переименуйте кластер.
- Отметьте несколько кластеров для объединения.
- Внутри кластера отметьте фото, которые нужно вынести в отдельный кластер.

## Файлы

- На карточке фото доступны copy/move/delete.
- Операции ограничены корнем архива и логируются.

## Логи

- «Логи» показывают индексацию, ошибки, AI-провайдер и файловые операции.
- Фильтруйте по debug/info/warn/error.

## Backup

- В «Настройки» нажмите «Создать backup SQLite».
- Файл копии создаётся рядом с базой API.
